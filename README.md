# AyayaMiner

一个打开即玩的高难度无猜扫雷游戏：保持紧凑格子并根据浏览器大小铺满棋盘（超大屏最多约 2500 格），地雷密度约 25%，每盘都经过逻辑 solver 完整验证，并在第一次翻开方格时开始计时。对局中改变窗口大小不会重开，新尺寸在下一盘生效。

## 操作

- “翻开 / 插旗”按钮：切换点击方格时的操作
- 左键 / 轻触：执行当前选择的翻开或插旗操作
- 右键 / 长按：添加或清除旗子
- 点击已翻开的数字：当周围标记数匹配时，快速展开相邻方格（插旗模式下同样有效）
- 方向键 / `Home` / `End`：在棋盘内移动焦点；`Enter` / `Space` 翻开
- `F`：为当前聚焦的方格添加或清除旗子
- `Esc` 或点击结果框外：收起结果，查看结局盘面

## 本地开发

```sh
npm install
npm run dev
```

完整验证：

```sh
npm run validate
```

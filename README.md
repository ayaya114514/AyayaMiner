# AyayaMiner

一个打开即玩的高难度无猜扫雷游戏：保持紧凑格子并根据浏览器大小铺满棋盘，地雷密度约 25%，每盘都经过逻辑 solver 完整验证，并在第一次翻开方格时开始计时。

## 操作

- “翻开 / 插旗”按钮：切换点击方格时的操作
- 左键 / 轻触：执行当前选择的翻开或插旗操作
- 右键 / 长按：添加或清除旗子
- 点击已翻开的数字：当周围标记数匹配时，快速展开相邻方格
- `F`：为当前聚焦的方格添加或清除旗子

## 本地开发

```sh
npm install
npm run dev
```

完整验证：

```sh
npm run validate
```
